# Севермакс — управление подогревателем по SMS

Приложение отправляет SMS-команды из инструкции подогревателя Севермакс 5000 mini
и разбирает ответы (HEATER ON/OFF, XHPZ OK, UP/DOWN TEM, CSQ, коды E-01…E-12).

## Как получить APK без Android Studio
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки.
2. Откройте вкладку Actions → Build APK → дождитесь зелёной галочки.
3. Внутри запуска скачайте артефакт severmax-control-apk, распакуйте и установите app-debug.apk.

## Через Android Studio
File → Open → выберите эту папку → Build → Build APK(s).

## Первый запуск
1. Разрешите отправку и приём SMS.
   На Android 13+ для установленного вручную APK может понадобиться:
   Настройки → Приложения → Севермакс → ⋮ → «Разрешить ограниченные настройки».
2. Вкладка «Настройки»: введите номер SIM подогревателя, выберите NFPZ или CGPZ.
3. Привяжите телефон в слот 1 (SMS TJSQ*123456*A).

## Telegram-бот
Бот работает внутри приложения: телефон с SIM принимает команды из Telegram,
отправляет их подогревателю по SMS и пересылает ответы в чат.
Настройка: вкладка «Настройки» → «Telegram-бот» (токен от @BotFather, ваш chat id, переключатель).
Команды: ▶ Запуск, ⏹ Стоп, 📊 Статус, /run 45, /temp 65, /boost 90 30.
Команды принимаются только от указанного chat id; сообщения старше 2 минут игнорируются.

## Поддержка нескольких моделей
Приложение и веб-страница поддерживают три профиля команд (вкладка «Настройки» → «Модель подогревателя»):
- **Severmax 5000-4mini** — K / G / C, NFPRZ*темп, XHRPZ*верх*низ, TJSQ*код*A-D, сброс HFCC.
- **Severmax 5000** — K или K*минуты / G / C, CGPZ*темп, TJSQ*код*1-4 (без режима догрева).
- **Severmax 5500 / PRO** — текстовые команды start/stop/status, REFS#код# для привязки (без установки температуры и догрева по SMS).
Экраны показывают только те функции, которые поддерживает выбранная модель.
